A smaller point

Bullet list
For a set of items where order doesn't matter.
Type - or * at the start of a line
  • Clear, scannable points
  • No particular order
  • Easy to skim
Numbered list
For steps or items where order matters.
Type 1. at the start of a line
  1. Update your resume
  2. Tailor it to the role
  3. Submit before the deadline
Quote
Set apart a quotation or a line you want to emphasize.

Smart features
Autosave
Stops typing for about 2 seconds and your draft saves itself. A small "Saved" note appears near the Save Draft button so you always know it's safe.
Clean paste
Paste in from Word, Google Docs, or any webpage — the messy fonts and styles get stripped automatically so it matches the rest of your article.
Word count & read time
Updates live as you type, so you always know roughly how long the finished piece will take to read.
