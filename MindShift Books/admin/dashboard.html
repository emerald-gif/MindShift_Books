Searches X's real Recent Search API by keyword — a genuine search, not just a lookup — grouping matching posts by author. Only covers the last 7 days of posts.

Costs real money per search. As of Feb 2026, X has no free API tier — roughly $0.005 per post read, so each search here costs about $0.05–$0.10 depending on result count, charged to whatever card is on your X Developer account.
